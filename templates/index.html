Instrumentation, not guesswork

The C program registers each object and labels its region. This avoids claiming that address values alone reveal a variable's lifetime or storage class.

!

What the size means

Sizes come from sizeof. A pointer's size is different from the size of the heap allocation it points to; MemScope reports the allocation separately.
